# ChangdongDemo1 — 아케인 와일즈 (Arcane Wilds)

Three.js로 만든 셀 셰이딩 3D 3인칭 판타지 액션 웹 게임입니다. 빌드 과정 없이 순수 ES 모듈로 동작합니다.

- 직업: 마법사 / 검사, 원소 5종(불·얼음·번개·바람·대지)
- 길 선택: 원소의 방랑자(5원소 전부) / 원소의 대가(한 원소 + 각성 궁극기·컷신 필살기·보조 스킬)
- 지형 상호작용(풀밭 화재, 상승 기류 활공, 수면 동결), 블록·대시·패링, 히트스톱 타격감
- 바람결 마을, NPC와 퀘스트 스토리, 세계관 인트로 컷신, 그래픽 옵션(풀 밀도 등)

## 실행

정적 파일 서버로 저장소 루트를 열면 됩니다(모듈 로딩 때문에 `file://`로는 동작하지 않음).

```bash
python3 -m http.server 8000
```

브라우저에서 http://localhost:8000 을 엽니다.

## 조작

WASD 이동 · Shift 달리기 · Space 점프/활공 · 마우스 좌/우 공격·차징 · Q 대시 · E(길게) 방어 · F 궁극기/대화 · R 필살기 · G 보조 스킬 · 1–5 또는 휠 원소 전환 · Esc 메뉴

## 구조

`ARCHITECTURE.md`에 모듈 구조와 인터페이스 계약이 정리되어 있습니다. `tools/`에는 헤드리스 플레이테스트 스크립트가 있습니다(`node tools/playtest.js`, Playwright 필요).
